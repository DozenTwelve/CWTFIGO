Claude, what the fuck is going on?

喊 Claude 的名字。它找出哪里不对，你点头才修，还会记住。

粘贴到 Claude Code
/plugin marketplace add DozenTwelve/CWTFIGO/plugin install cwtfigo@cwtfigo

然后输入 cwtfigo。它提出给这台电脑做个体检，就说明装好了。

怎么用

喊它的名字

输入“CWTFIGO”，再说哪里不对。或者只输入“cwtfigo”，它会提出做个体检。

读之前先问

每个新脚本运行前，Claude Code 都会先问你。会改动电脑的事，每次都问。

它记得

笔记留在你的电脑上，一台机器一个文件夹，经 SSH 连到的其他机器也一样。下次从这里接着来。

之后不用 AI

Claude 给每台机器写好它自己的体检和保养脚本。一个小菜单不经过 Claude 也能跑它们，支持 Mac 和 Linux。

常见问题

笔记存在哪儿？

存在你电脑上的 ~/.cwtfigo，删掉这个文件夹就没了。Claude 读到的内容会经过 Anthropic，Claude Code 里的一切都是这样。

需要装什么？

Claude Code、git 和 python3。Mac 上先运行 xcode-select --install。第一次用 Opus 效果最好：/model opus。

它会动我没让它动的东西吗？

只有你喊它名字时它才开始，也只碰你指给它的那台电脑。

出问题了怎么办？

告诉它“CWTFIGO，刚才那个没用”。它会起草一份 bug 报告，你点头才发出去。也可以自己开一个 issue。
